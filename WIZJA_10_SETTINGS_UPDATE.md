# HAULWAY — WIZJA 10: Settings

- Replaced the old Settings list screen with a two-panel landscape layout.
- Removed the Settings page's top back arrow, `SETTINGS` heading and top-right map shortcut.
- Added a left category rail: Map Settings, Map Appearance, Navigation, Warnings, Display, Voice Guidance, Units & Regional, Offline Maps and About.
- Added the Map Appearance panel with Day / Night / Auto selection, POI, Traffic and 3D building switches, and a cycling Map style selector.
- Kept the six-item bottom navigation bar and its existing destinations.

Note: the visual controls are now interactive UI state. Connecting every new setting to the map engine/device preferences is a separate integration step; this update does not claim that toggles already alter map rendering or persist after app restart.
