# HAULWAY Navigation — Stage 2: Driving navigation screen

The driving navigation screen uses a full-height 70:30 horizontal layout:
- 70% map canvas on the left, including manoeuvre, speed, trip summary and map controls overlays.
- 30% upcoming manoeuvres / services rail on the right.

The bottom six-item game-style tile navigation bar has been removed from the driving screen. Navigation back to Home and other sections remains available through the app's existing screen flow; the driving view itself is dedicated to navigation.

The map artwork and route values remain illustrative placeholders. Live map tiles, truck-aware routing, GPS position updates and voice turn-by-turn guidance still require integration.
