# HAULWAY VISION 14

This package is the complete Android Studio project based on the supplied GitHub ZIP.

1. Open the `HAULWAY-Navigation-main` folder in Android Studio.
2. Allow Gradle sync to finish.
3. Keep API keys in `local.properties` or GitHub repository secrets; do not commit keys.
4. Build with **Build → Build Bundle(s) / APK(s) → Build APK(s)**, or run `./gradlew assembleDebug`.
5. See `VISION_14_CHANGELOG.md` for the changes and validation notes.

Package version: `1.4.0-vision14` (versionCode 5).
